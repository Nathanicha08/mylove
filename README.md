# Three Hearts 2.0 — เงาในหัวใจ

เกม Dating Simulation ภาษาไทยแนวรักสามเส้าในโรงเรียน สร้างด้วย HTML, CSS และ JavaScript ล้วน

## เปิดเล่นในเครื่อง
แตกไฟล์ ZIP แล้วเปิด `index.html` ด้วย Chrome, Edge หรือ Firefox

## ฟีเจอร์
- เนื้อเรื่องหลายเส้นทางและตัวเลือกที่มีผลต่อเนื้อเรื่อง
- ค่าความรักของคิน/เมษา ความไว้ใจ และความหึงหวง
- ฉากจบหลายแบบ รวมฉากจบลับและฉากจบหักมุม
- บันทึกอัตโนมัติด้วย localStorage และปุ่มบันทึก/โหลด
- เพลงประกอบสร้างด้วย Web Audio API (ไม่มีไฟล์เพลงภายนอก)
- เสียงอ่านภาษาไทยผ่าน SpeechSynthesis ของเบราว์เซอร์

## หมายเหตุเรื่องเสียง
เสียงพูดใช้ระบบ Text-to-Speech ที่มีในอุปกรณ์/เบราว์เซอร์ ไม่ใช่ไฟล์เสียงพากย์ AI ที่สร้างแยกไว้ คุณภาพและการมีเสียงภาษาไทยขึ้นอยู่กับเสียงที่ติดตั้งในเครื่อง หากไม่มีเสียงไทย เบราว์เซอร์อาจใช้เสียงเริ่มต้นหรือไม่อ่านภาษาไทยได้
เพลงประกอบเป็นทำนองสังเคราะห์แบบง่ายในเบราว์เซอร์

## นำขึ้น GitHub Pages
1. สร้าง repository ใหม่บน GitHub
2. อัปโหลด `index.html` และโฟลเดอร์ `assets` ทั้งโฟลเดอร์
3. ไปที่ Settings → Pages
4. เลือก Deploy from a branch → Branch `main` → Folder `/ (root)` → Save
5. เปิด URL ที่ GitHub Pages แสดงให้

**สำคัญ:** ต้องอัปโหลดโฟลเดอร์ `assets` พร้อมภาพทั้ง 3 ไฟล์ ไม่เช่นนั้นภาพตัวละครจะไม่แสดง
การบันทึกเกมอยู่ในเบราว์เซอร์/อุปกรณ์ที่เล่น ไม่ได้ซิงก์ข้ามเครื่อง
